# Rent It — सिस्टम नियम (हिंदी)

- सभी विवादों में Rent It का निर्णय अंतिम होगा।
- किराएदार और मालिक के बीच सीधा संपर्क प्रतिबंधित है।
- फिट से संबंधित समस्याएँ विवाद योग्य नहीं हैं।
- वस्तु की स्थिति केवल प्लेटफ़ॉर्म द्वारा ली गई फ़ोटो से तय होगी।
- सभी किरायों पर डिपॉज़िट अनिवार्य है।
- सभी भुगतान Rent It द्वारा सुरक्षित रूप से रखे जाते हैं।
